# Stanislaus Humanists website

The source code for <https://stanislaus-humanists.org>, the website of the
Stanislaus Humanists.

- Built with [Solid](https://www.solidjs.com) and Vite.
- Only HTML, CSS and JavaScript are deployed. 
- The site is hosted on Cloudflare Workers. 
- The code is in [app/](app/).

Full technical information for the site (hosting, deployment, the domain, and
how to verify and troubleshoot it) is kept separately and is available upon
request.
